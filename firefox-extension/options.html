Tree Style Tab Integration

When the Tree Style Tab add-on is installed and enabled, the extension can use its API to work with the tab tree:

  • New tabs are opened as children of the active tab
  • The tab list is shown as an indented tree
  • Grouping tabs creates Tree Style Tab groups
  • Closing a tab can keep its child tabs
